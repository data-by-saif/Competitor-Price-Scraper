# Competitor-Price-Scraper

Automated E-Commerce Competitor Tracker

Built a Python-based web scraping tool using Requests, BeautifulSoup, and Pandas to collect and analyze product data from competitor websites.

Features:

Scrapes product information such as title, price, stock availability, and product links.
Parses HTML content and extracts data from product listing pages.
Cleans and converts price data into numeric format for analysis.
Stores collected data in structured Pandas DataFrames.
Exports results to CSV files for reporting and further analysis.
Provides a simple workflow for monitoring competitor pricing and inventory trends.

Tech Stack:

Python
Requests
BeautifulSoup4
Pandas
CSV

Output Example:

Product Name
Price (GBP)
Availability Status
Product URL
